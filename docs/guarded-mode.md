# 捕获模式与一致性边界

## 两种捕获模式

CLI 参数 `--capture-mode`：

| 模式 | 适用前提 | 报告标记 |
| --- | --- | --- |
| `static`（默认） | 载荷树静态、可信、本地、无符号链接，沿用 v1 契约 | 无额外字段，报告结构与历史完全一致 |
| `guarded` | 清单所在目录可信且不变；载荷树在核验期间可能被写入或替换 | 顶层 `capture_mode:"guarded"`，结果含 `observed_stable:true` |

默认 `static` 保持原契约：不传参数时的命令行行为、退出码、报告字节结构均不变。
两种模式共享同一份清单校验（`model.validate`）：路径规范、2000 项上限、单文件 8 MB、
总量 32 MB、SHA256 小写十六进制、重复路径拒绝、根目录不得为符号链接。

## guarded 模式保证的观测

1. **锚定根描述符**：先打开可信清单目录，再以 `O_NOFOLLOW|O_DIRECTORY` 逐段打开
   payload_root 链并长期持有根描述符；后续所有解析都基于 `dir_fd` 的相对打开，
   路径遍历不依赖可被替换的全局路径名。
2. **不跟随符号链接**：每个路径段都先 `fstatat` 语义（`os.stat(..., follow_symlinks=False)`）
   判定类型。链接、FIFO、套接字、设备等非普通文件永不打开读取，分别落为
   `unsafe_link` / `not_regular_file` 审计发现；清单外链接只记录，不访问目标。
3. **FIFO 不阻塞**：普通文件以 `O_RDONLY|O_NOFOLLOW|O_NONBLOCK` 打开，目录段打开同样带
   `O_NONBLOCK`。任何非阻塞读取失败按执行失败处理（退出 2），不会把未读文件报成 verified。
4. **采集前后全树指纹**：捕获前与末次遍历各做一次全树快照，逐条目比较
   路径、类型（`S_IFMT`）、设备号、inode、大小、纳秒 mtime、纳秒 ctime，
   同时复核根链每一段的同名描述符与根 inode 身份。
5. **每文件读取前后比对**：读取前记录同一描述符的指纹；打开后用 `fstat` 复核
   设备号/inode 与类型；读取结束再次 `fstat` 比较全部指纹字段，并核对实读长度与
   读取时大小一致。
6. **失败语义**：任一观测变化（含根段替换、父目录替换、读中追加/改写、末次遍历新增
   或删除文件、读前 inode 切换）或 I/O 失败，抛出 `GuardInstability`/`OSError`，
   CLI 退出 2，且因报告仅在全部检查通过后经原子替换发布，旧报告保持不变。
7. **稳定差异仍是审计发现**：核验期间未观测到变化时，稳定的缺失、符号链接、
   非普通文件、非目录父级、大小/哈希差异仍按 static 模式同样的状态字段输出；
   哈希不符是 `mismatch` 发现而非命令失败。

## observed_stable 的边界

成功报告中的 `observed_stable:true` 只保证上述**离散采样点上的观测**稳定：
采集前快照、各文件读取前后描述符、末次快照之间未观测到差异。

它**不保证**两次采样之间不存在不可观测的改写——例如“改写后精确还原”、
在纳秒时间戳分辨率内完成的同尺寸替换，或文件系统未如实上报时间戳的情形。
这不是事务快照、不是原子只读视图，也不提供挂载边界隔离或并发写者排除。
需要强一致时，应在载荷树静默（无写者）窗口或块级快照上运行。

## 资源上限与描述符

沿用 static 模式全部上限：单文件 ≤8 MB、清单期望总量与实读总量 ≤32 MB、
清单 ≤2000 项、全树库存 ≤5000 项、JSON ≤8 MB。
`TreeGuard` 是上下文管理器：根链描述符在关闭时统一回收；全树快照临时打开的
子目录描述符在当次快照结束即关闭；每文件打开的描述符在该文件处理完立即关闭，
异常路径同样关闭。测试通过 `/proc/self/fd` 断言成功与失败后均无描述符泄漏。

## 报告与退出码

- 成功：退出 0，guarded 报告顶层多 `capture_mode`，`result` 内多 `observed_stable`，
  其余字段与 static 完全同名同义。
- 契约失败（清单格式、重复路径、根为符号链接、超限等）：退出 2，旧报告保留。
- 观测不稳定或 I/O 失败：退出 2，旧报告保留，stderr 给出原因。
- 报告路径必须在 payload 树外、不得与源相同、不得为符号链接，两种模式一致。

## 竞态测试方法（同步屏障）

`tests/guarded_mutator.py` 与进程内屏障回调在捕获管线的确定节点注入变更，
不依赖 sleep 竞时：

| 屏障点 | 注入场景 | 断言 |
| --- | --- | --- |
| `read_chunk`（首块读完） | 检查后把已读文件换成指向树外目标的符号链接 | 不读链接目标、无 verified、退出 2、旧报告不变 |
| `read_chunk` | 换成指向 FIFO 的符号链接 | 不阻塞（5 秒/10 秒超时断言）、退出 2 |
| `read_chunk`（嵌套文件） | 父目录整体替换为新目录 | 末次快照观测到变化、退出 2 |
| `read_chunk`（大文件） | 读取中追加字节 | 读前后指纹/实读长度比对失败、退出 2 |
| `pre_final_snapshot` | payload 根目录整体替换 | 根链同名描述符变化、退出 2 |
| `pre_final_snapshot` | 末次遍历前新增文件 | 全树快照差异、退出 2 |
| 常驻 FIFO / FIFO 符号链接 | 无写者 | 立即返回 `not_regular_file`/`unsafe_link`，不阻塞 |

另含静态兼容测试：同一 fixture 与多组临时树下，guarded 去掉 `observed_stable`
后与 static 结果逐字段相等；CLI 默认 static 报告不含 `capture_mode`。
